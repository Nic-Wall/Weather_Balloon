Out of order, once again. The first time is usually the hardest, but it's also usually the most rewarding as the most is learned.
After uploading to Github and attempting to work across two distributions (Arch (desktop) and Mint (laptop)) I found building the project to be inconsistent, likely due to the mismatch in `gcc` versions. Largely, this would have little to no effect on a project like this except for the need to install dependencies like `bison` on every device in which one wishes to compile the project.
Therefore, the best course of action is to build out my own toolchain. One that can be installed and used in exactly the same manner across any device/ distribution.
The simplest option is to install a pre-made toolchain that matches all my requirements. It needs a compiler, a linker, and a list of runtime libraries. It also needs to be a cross-toolchain, since I'm compiling for an ARM SoC. In the books I've read (predominantly Mastering Embedded Linux) I've become most familiar with [Bootlin](https://toolchains.bootlin.com/releases_aarch64.html), so it's what I'll choose to use.
