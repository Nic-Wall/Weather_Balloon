# Setup
As the book states, a cross compiling toolchain does exist in my distribution's package list...
```shell
$ apt search aarch64-linux-gnu
...
gcc-9-aarch64-linux-gnu
gcc-10-aarch64-linux-gnu
gcc-11-aarch64-linux-gnu
gcc-12-aarch64-linux-gnu
gcc-13-aarch64-linux-gnu
gcc-14-aarch64-linux-gnu
...
```
The [RockPro64 Wiki](https://wiki.pine64.org/wiki/Cross-compiling) confirms the books assessment in the installation of `gcc-aarch64-linux-gnu`, which pulls `gcc-13-aarch64-linux-gnu` and it's dependencies...
