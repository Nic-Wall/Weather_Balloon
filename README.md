A weather balloon project built to learn (and show off) a little bit about embedded Linux and engineering. This project is functionally a self-made weather station, just put in a box and sent above the clouds.
This project includes...
- Configuration changes made to the Linux kernel, to keep it light. Basically removing whatever wasn't absolutely necessary
- Custom written drivers for the sensors used to collect data
- Programs using said drivers to acquire said data
- Docs on the entire process, mistakes (learning experiences) and all, as well as notes on why choices were made as they were
